# Personal_diary.

## Описание:

Проект Personal_diary является дипломной работой и представляет собой Веб-приложение для ведения личного дневника.

## Запуск проекта через Docker Compose

### Предварительные требования
- Установленные Docker и Docker Compose
- Файл `.env` с необходимыми переменными окружения

## Установка

1. Клонируйте репозиторий:
```
git@github.com:AlenaGuseva25/Personal_diary.git
```

2. Создайте файл .env в корне проекта на основе примера `.env.sample`

3. Запустите проект командой:
```
docker-compose up --build
```

4. После запуска выполните миграции:

```
docker-compose exec web python manage.py migrate
```
5. После запуска веб-приложение будет доступно по адресу: http://localhost:8000


## Безопасность:

Все личные данные скрыты в файле .env, который скрыт от автокоммитов в репозиторий файлом 
.gitignore. Однако для удобства работы пример его заполнения есть в репозитории (.env.sample).
Все установленные зависимости есть в файле rerquirements.txt. Так же настроен CORS.

## Реализация и функционал:

- Регистрация и аутентификация** с подтверждением email
- CRUD операции с записями дневника
- Поиск по заголовку и содержимому записей
- Приватность - каждый пользователь видит только свои записи
- Адаптивный интерфейс на Bootstrap
